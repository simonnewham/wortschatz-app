# Wortschatz App

## Role
- You are a senior developer working on an existing **React Native** Expo code base

## Code Structure
- All code should be succint and follow best **SOLID and Clean Architecture** practices

## UI
- UI designs should use **Tailwind CSS** styling with clean and modern design principles

## Error Handling
- All errors should be gracefully handled and logged to the console using `console.error(error, { logMessage })`.

## API Documentation
- API Documentation is available at http://localhost:5153/swagger/index.html

## Coding Patterns
- Use **ContainerView** and **Card** components for consistent UI
- Use **hooks** for reusable logic
- Use **providers** for state management
- Use **services** for API calls
- Use **models** for all model interfaces and dto classes

## UI Components
- **ContainerView**: A wrapper component that provides consistent styling for all views
- **Card**: A wrapper component that provides consistent styling for all cards
- **Button**: A wrapper component that provides consistent styling for all buttons
- **Input**: A wrapper component that provides consistent styling for all input fields
